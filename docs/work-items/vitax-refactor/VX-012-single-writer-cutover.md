## 验收

- [ ] 旧URL/ID可映射，多来源、人工Wiki修订、已有翻译和图片保留；unknown历史字段不编造。
- [ ] 先小批幂等导入和差异审阅，再增量追平；不兼容索引再派生，不全量重跑模型。
- [ ] 缺失证据的旧关系保留待核，不伪装为已验证公开关系；先验恢复再切换。
- [ ] PC唯一生产调度/写入；云端只有发布和读取，旧定时器/重复服务逐项停止并可回退。
- [ ] VitaX、MCP、vitaclaw-site实际访问与备份恢复均有证据。
- [ ] 原始数据永久删除、不可逆迁移、身份凭据或付费资源变更仍需ADR0002明确授权。

**验证：** 导入映射/计数/抽样内容与来源、重跑、增量差异、前后调度、真实周期、业务查询与回退。

**执行边界：** 只写主控派工的互斥路径；保护原始数据与无关 WIP，不自动 commit/push。远端写入须绑定具体候选/生产任务、当前主机与源码验证，ADR 0002 四类例外始终有效。
