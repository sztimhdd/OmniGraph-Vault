- [ ] 先现场只读核实相关旧存储的实际schema、数量、来源及修订关系；不得把“上千篇”当已验证数量，也不要求全项目漂移审计。

- [ ] 保存原始导出并核内容保全；缺失时间/作者/证据为unknown。旧译文不是新生成解读，结构转换成功不是语义重新审核通过。

- [ ] 仅既有公开标记或明确公开材料的受限投影可进入公开候选；原文/全文译文默认私有，不因迁移自动公开。

**Scope:** 一个有证据的来源格式适配器＋复用当前合同和build，不建通用ETL。代码位置由主控根据现场schema指定；source只读、候选可写，禁止模型请求、生产修改和全库转换。
