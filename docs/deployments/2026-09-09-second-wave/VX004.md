# VX004 offline single-fixture preflight

## Scope

`scripts/vitax_isolated_ingest.py` creates a new empty run directory under an
explicit, existing parent and writes `VX004_OFFLINE_PREFLIGHT.json`. It accepts
one fixture directory containing `article.md` and `metadata.json`.

It rejects `/`, the user home directory, the system temporary root, path
traversal, symlink parents or parent ancestors, and symlinked required fixture
files. These checks run before a run directory is created. Its four explicit
isolation keys are
`OMNIGRAPH_BASE_DIR`, `RAG_WORKING_DIR`,
`OMNIGRAPH_CHECKPOINT_BASE_DIR`, and `KOL_SCAN_DB_PATH`; images and entity
buffers derive from the isolated base path. No existing directory is removed.

## Offline contract

The preflight does not import `ingest_wechat`, call `get_rag`, run
`ingest_article`, create a model client, open a network connection, or spawn a
subprocess. Its environment is a new allowlist: it sets
`OMNIGRAPH_LOAD_ENV=0`, isolated base/RAG paths, `nanovectordb`, and disables
enrichment. It does not copy inherited credentials into the plan.

This is a plan artifact, not a sandbox or an ingestion result. Python-level
environment control and monkeypatches would not prove child-process isolation;
there is intentionally no live-execution switch in this harness.

## Reused future entry path and gates

Source tracing identifies the later authorized path as
`ingest_wechat.get_rag()` -> `ingest_wechat.ingest_article()` ->
`rag.finalize_storages()`. `scripts/probe_e2e_v3_2.py` has the same entry path,
but its top-level executor calls `shutil.rmtree`; it is not invoked or wrapped.

The first live sample may explicitly select `nanovectordb` with this new empty
RAG directory. Qdrant is not a prerequisite for this preflight or that sample;
it remains a separate backend check if later selected. Before any live
invocation, the controller must authorize and record an explicit LLM callback,
storage backend, real network/process isolation evidence, and post-finalize
document/query evidence. Embedding also needs an explicit choice:
`OMNIGRAPH_LOCAL_EMBED=1` selects the local endpoint whose current default is
`http://localhost:7997/embeddings`; without it, the current source takes its
external Vertex/Gemini path. `OMNIGRAPH_LOAD_ENV=0` prevents loading
`~/.hermes/.env`; it does not itself clear inherited credentials or block
network access in production code.
