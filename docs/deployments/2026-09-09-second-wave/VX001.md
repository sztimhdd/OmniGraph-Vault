| 状态类别 | 变量 / 契约 |
| --- | --- |
| 基础运行文件 | `OMNIGRAPH_BASE_DIR`，覆盖 images、entity buffer、canonical map 等基础目录。 |
| LightRAG 文件存储 | `RAG_WORKING_DIR`。 |
| checkpoint | `OMNIGRAPH_CHECKPOINT_BASE_DIR`。 |
| SQLite | `KOL_SCAN_DB_PATH`。 |
| 禁止默认 env 文件加载 | `OMNIGRAPH_LOAD_ENV=0`。该值不会清除继承凭据或阻止网络出口。 |
| 本次 E2E 向量后端 | 显式 `OMNIGRAPH_VECTOR_STORAGE=nanovectordb`。 |
| 后续 Qdrant 验收 | 显式、唯一的 `QDRANT_WORKSPACE` 或独立实例；不得以 `RAG_WORKING_DIR` 代替向量隔离证据。 |
