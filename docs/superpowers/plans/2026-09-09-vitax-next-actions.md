## 规格采用的默认处理

- [INFERRED] 优先复用代码和已安装运行环境，不开展大规模重写。Hermes/Astra 的适配先定位到具体模型调用接口，不机械地每个 LLM 调用启动一个完整 Agent。
- [INFERRED] 完整原始资料服务内部加工，公开文字以摘要、深度解读、专题和 Wiki 为首版默认；这是设计默认，并非用户逐字批准的全文策略。关键图片按已确认的价值选图与出处 caption 规则执行。
- [INFERRED] 访客模型服务与内部生产模型分开；用户 BYOLLM 生成失败不使用站点自有付费 Key 兜底。云端检索和 embedding 依赖必须独立于 PC。
- [INFERRED] Codex 与 Hermes 可能共享订阅额度，不能假定升级 Codex 可以绕过额度耗尽；额度故障按已确认的暂停通知规则处理。
- [INFERRED] 修复尝试需有界并留下新证据；具体阈值作为工程默认，不将此前未确认的“两轮直接向用户求助”恢复为要求。
- [KNOWN] 永久删除原始数据、不可逆数据库迁移、账户或凭据变更、增加付费资源，保留用户明确批准边界。
