# VitaX 真实读者站与安全公开知识规格

**日期：** 2026-09-20  
**状态：** ready for implementation  
**上位合同：** ADR 0003、ADR 0004、`VITAX_REFACTOR_SPEC.md`

**2026-10-02范围澄清：** 本文限定匿名公开阅读。维护者本地私有文章库按[三模块规格](VITAX_THREE_MODULE_EXECUTION_SPEC.md)独立只读全部已存资料，不以建图成功或公开accepted为前置；本文的全文公开限制继续有效。

## 问题

[KNOWN] 已接受的两来源 release `release-20260910t021435z` 可从 SQLite 读取文章知识、Wiki、关系和证据，但尚无真实读者站验收。

[KNOWN] 旧知识试迁移已经把 20 篇文章零 LLM 导入私有候选；它们都未获公开资格。当前迁移投影若把记录标为 public，会把完整译文作为知识正文并逐段生成公开证据。这与“完整原文和译文默认私有，公开只含已接受知识、Wiki与必要摘录”的产品边界冲突。

[INFERRED] 在公开投影合同修正前接入旧知识，会把隐私错误固化进页面、HTTP 与 MCP。首个 Sprint 应先完成安全公开切片和真实站点，再扩大全量迁移或高级检索。

## 本 Sprint 的产品结果

维护者能在本机启动一个读取真实 release 的 VitaX 站点。访客可以：

1. 浏览和搜索已发布知识条目；
2. 打开文章解读与专题 Wiki；
3. 查看关系、引用摘录、来源链接与定位信息；
4. 在移动端或刷新详情 URL 后继续使用；
5. 对未知条目得到真实 404，对空库、加载失败和资源失败得到真实状态。

完整原文、完整译文、私有候选、运行记录和未批准图片不能通过页面、静态资源、HTTP 或 SQLite 公开读库读取。

## 最小范围

- 复用现有 `KnowledgeReader`、SQLite FTS5、两来源真实 release 与 `KB-v2-site.zip`。
- 公开内容只允许白名单字段：已接受知识正文、Wiki正文、必要证据摘录、来源元数据、类型化关系和已批准图片 caption。
- 网站与后续 MCP 共用一套查询逻辑；本 Sprint 只做站点所需的最小 HTTP 表面。
- 页面固定并显示同一个 `release_id`，不得在单次请求中混读版本。
- 只保留四类界面：列表/搜索、文章详情、Wiki详情、证据/来源面板。

## 明确不做

- 不部署阿里云，不切换生产，不停旧调度。
- 不执行 1,257 篇全量迁移，不恢复 41 篇缺正文记录。
- 不调用 LLM，不重翻译，不重建 LightRAG/Qdrant，不引入向量库或 Agent 框架。
- 不实现 BYOLLM、复杂多跳、社区发现、后台管理、评论或个性化。
- 不实现 release 过期、410、跨请求生命周期或通用发布平台。
- 不保留 ZIP 中的设计说明弹窗、评审工具栏、反馈弹窗、假统计或 mock 推荐。

## 数据合同

### 私有资产

私有资产包含原始正文、完整译文、抓取物、运行记录、待核关系、未批准图片和迁移候选。迁移成功、质量结论与公开资格继续独立记录。

### 公开资产

公开投影必须从显式 accepted 的 `KnowledgeRevision` / Wiki 与它们引用的必要证据生成。仅把 `DocumentRevision.publication=public` 或拥有完整译文，不足以生成公开知识正文。公开投影不得从全文译文自动合成逐段证据。

### Release

本地验收包至少包含公开 SQLite、站点构建产物、白名单图片与 manifest。manifest 记录 release ID、文件 hash 和生成时间。构建失败不得覆盖已存在的验收包。

## 验收场景

1. 真实两来源 release 能完成列表 → 文章 → 证据、Wiki → 两来源、关键词搜索三条路径。
2. 页面、HTTP、SQLite 和 manifest 返回同一 `release_id`。
3. 详情 URL 直接打开和刷新可用；未知 ID 返回 404。
4. 页面无 mock 回退、假统计和不可用按钮；空、错、加载和图片失败状态真实。
5. 键盘可完成主要路径，移动端无阻断，正文与来源在交付 HTML 中可发现，而非空 SPA 壳。
6. 注入私有原文和完整译文 sentinel 后，公开 SQLite、HTTP、HTML、JS 数据和静态资源均不包含 sentinel。
7. 未获 accepted knowledge/Wiki 的迁移记录即使 publication 标为 public，也不得生成全文公开知识。
8. 本地 release 目录可直接作为后续云端复制输入，但本 Sprint 不证明云端发布。

## 测试接缝

1. **公开投影边界：** 从私有候选构建全新公开库，fresh process 读取并扫描公开字节；这是阻止全文泄露的主接缝。
2. **共享查询边界：** HTTP 只调用同一读模型，测试 search/read/related/evidence、404 和 release 一致性。
3. **浏览器边界：** 对实际构建产物执行固定路径 UAT，检查内容、导航、刷新、键盘、移动端和网络错误。
