# VX-009B3 — 最多5个旧文章解读与Wiki候选形成真实可读release

**Parent:** VX-009B。  
**Blocked by:** VX-009B1、VX-009B2。  
**Status:** proposed / blocked-on-B1-B2（尚未实施）。

## 可验收交付

最多5个真实候选逐项审计，覆盖旧文章已有解读和旧Wiki；至少各1份新增合格知识进入同版站点/MCP，原已接受内容与来源保全，用户可以搜索并追溯证据。此处接续已完成的1419篇私有文章保全，不重新迁移原文/译文。

- [ ] 先只读核已有文章解读与稳定来源/修订映射，仅输出计数/ID/hash；候选至少覆盖一篇文章解读和一页富内容Wiki，不取64占位页凑数；各项有kind、artifact/hash、来源解析、语言、决定和具体原因。
- [ ] 仅所选知识/必要引用进入新包；旧图裸source_id、共同出现、缺摘录或语义冲突保持待核。
- [ ] 当前全部基线记录逐ID/hash保留，source/private/前版字节不变；新包失败不替换前版。
- [ ] 中文短词/新增词→文章解读→原文章来源/证据、Wiki→跨来源证据、实体→关系→证据、刷新与手机主路径真实通过；article/wiki过滤及MCP实际协议与HTTP同版同JSON。
- [ ] 文章解读允许单源，Wiki必须跨来源；原文、译文及派生全文不自动当公开解读。任一类无合格新增即如实未达完整内容门；缺已有解读列待生产，不自写内容或补造第二来源，不无界扩大审核。
