## 验收

- [ ] 审阅并复用 ZIP 的现有视觉和基础组件，不重写整站。
- [ ] 删除假统计、mock 数据/回退、评审工具栏、设计说明、反馈弹窗和不可用动作。
- [ ] 页面与最小 HTTP 接口共用现有知识读模型，响应固定同一 `release_id`。
- [ ] 文章、Wiki、关系、证据摘录、来源链接与已批准图片 caption 可读。
- [ ] 未知 ID 返回 404；空库、加载失败、图片失败和后端错误显示真实状态。
- [ ] 详情 URL 可直接打开和刷新；移动端与键盘主路径无阻断。
- [ ] 标题、正文与来源可从交付 HTML 读取，不能只是空 SPA 壳。
- [ ] 不调用模型、不连接远端、不加入第二后端或新 UI 框架。
